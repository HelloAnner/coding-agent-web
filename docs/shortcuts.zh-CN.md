# 快捷键

这份文档描述**目前实际生效**的全部快捷键，以及每个键到底做了什么。
代码在 `lib/shortcuts/`，改键只改那一处。

## 一分钟版

| 键 | 作用 |
|---|---|
| `⌘↑` / `⌘↓` | 侧栏里看得见的会话，上一个 / 下一个 |
| `⌘⇧↑` / `⌘⇧↓` | 上一个 / 下一个**未读**会话 |
| `⌃⇧↑` / `⌃⇧↓` | 上一个 / 下一个**项目**（每个项目的第一条会话） |
| `⌃⌥↑` / `⌃⌥↓` | 上一个 / 下一个**正在运行**的会话 |
| `⌃N` | 在当前会话的项目下新建会话 |
| `⌃↵` | 焦点回中间的对话输入框 |
| `⌃E` | 退出编辑区（焦点离开输入框） |
| `⌃E` `⌃E` | 焦点到左侧会话 / 项目树 |
| `⌃E` `D` | 归档当前会话 |
| `⌃E` `R` | 让 AI 重新生成会话标题 |
| `⌃E` `N` | 新建会话 |
| `j` / `k` | 上下滚对话（手不在输入框里时） |
| `↵` | 焦点回输入框（焦点在按钮上时仍算那个按钮的） |

## 设计原则

1. **一个 `⌘`+字母 都不用。** `⌘T ⌘W ⌘L ⌘F ⌘R ⌘1–9` 那些属于标签页、地址栏、刷新、查找，抢了就是坏掉。这套键只用 `⌘↑↓`、`⌘⇧↑↓`、`⌃⇧↑↓`、`⌃⌥↑↓`、`⌃E`、`⌃N`、`⌃↵`，加上没有输入框时的裸 `j` / `k` / `↵`。
2. **匹配才接管。** 只对上面的键 `preventDefault`；其余键（滚动、`⌘F` 浏览器查找、Tab 焦点、输入法）原生行为一点不动。
3. **输入框是插入模式。** 焦点在能打字的地方时，裸键全是那个控件的；带修饰的跳转（`⌘↑↓`、`⌘⇧↑↓`、`⌃⇧↑↓`、`⌃⌥↑↓`、`⌃N`）照跳，因为它们存在的理由就是"人在写着字，想去看别的"。
4. **菜单、对话框、终端里的键不抢。** 终端里键盘归 shell，整块区域都不碰。
5. **输入法优先。** 候选期间（`isComposing` / keyCode 229）一个键都不拦。
6. **草稿不丢。** 跳走再回来，输入框里没发出去的字还在（草稿按会话存在 `draft-store`）。

## 一、跳会话：`⌘↑` / `⌘↓`

- 走的顺序 = 侧栏当下的显示顺序：置顶区在上，然后各项目分组、组内按侧栏排的顺序。
- **只走看得见的**：折叠起来的分组、被 `show more` 收起来的会话、归档视图之外的归档会话都不参与。归档视图打开时走的就是归档列表。
- 到头**绕回**（最后一条再往下 = 第一条），所以按着就能一直转。
- 选中后列表自动滚到那一行（列表是虚拟的，滚到才会挂载）。
- 焦点不动，方便连按；要打字就 `⌃↵` 或 `↵`。

## 二、跳未读：`⌘⇧↑` / `⌘⇧↓`

- 只走侧栏里带未读标记的会话；顺序、绕回、滚动同上。
- 跳过去就算读过：现有的"选中即清未读"逻辑，不需要再按别的键。
- 目标藏在**折叠的分组**里时，第一下会先把那个分组展开（组头上本来就显示未读/运行中的数量），第二下就进去了。

## 三、跳项目：`⌃⇧↑` / `⌃⇧↓`

- 落在每个项目分组里的**第一条**会话，整组对话一步跳过——一个文件夹里有几十条也只是一步。
- 从当前会话所在的项目往后（或往前）走，不会因为当前会话不是第一条就回到开头。
- 折叠的项目、没会话的项目跳过；置顶区和归档视图不参与。
- 同样绕回、自动滚到可见。

## 四、跳运行中：`⌃⌥↑` / `⌃⌥↓`

- 只走现在还挂着转圈的会话（`runningSessionIds`）。
- 目标在折叠分组里时，第一下展开那个分组，第二下进去。
- 用来在几条并行跑着的会话之间来回看，不打断任何一条。

## 五、`⌃N`：在当前项目下新建会话

- 项目 = 当前会话所在的那个（worktree 会话就是那个 worktree），没有会话时是侧栏当前的目录。
- 哪里按都行，包括正在输入框里写字的时候；草稿按会话留着。
- 新建后光标直接落在新会话的输入框里。

## 六、`⌃↵` 和 `↵`：回输入框

- 焦点不在输入框、按 `⌃↵` → 光标进当前会话的输入框。焦点已经在输入框里时 `⌃↵` 不接管（那里它是"发送"，见下面的发送设置）。
- 焦点在页面空白处按 `↵` 也回输入框；但焦点在某条会话行、某个标签、某个菜单项上时，`↵` 仍是那个控件的（否则整块界面会变哑）。

## 七、`⌃E`：退出编辑区，兼一串命令的开头

第一步永远是同一件事：**把焦点从输入框交回页面**。之后 1.2 秒内再按一个键，就是对侧栏的动作；不按就只是退出。

| 第二下 | 作用 | 细节 |
|---|---|---|
| `⌃E` | 焦点到左侧会话 / 项目树 | 选中行不在可视范围时先滚过去再聚焦；一条会话都没有时焦点给树里的第一行，再不行给工具栏的搜索按钮 |
| `D` | 归档当前会话 | 连同它的子智能体一起；运行中的会被拒绝并提示（否则会立刻回到树里）；归档有撤销 toast |
| `R` | 让 AI 重新生成会话标题 | 就是工具栏那个"生成会话标题"，没有消息 / 正在生成时不动 |
| `N` | 新建会话 | 同 `⌃N` |

- 按下后底部会出现一条提示，列出这几个键，1.2 秒后自己消失。加命令只改 `lib/shortcuts/leader.ts` 那张表，提示条自动跟着变。
- 第二下敲的是字母，不需要继续按住 `⌃`。
- 第二下如果是不认识的键（比如 `j`），这一轮结束，那个键按它自己的规矩走——`j` 照样滚对话。
- `⌃E` 在菜单、对话框、终端里不触发。

## 八、裸键：`j` / `k` / `↵`

- `j` / `k`：上下滚**对话区**，每按一次 120px，按住可以连滚。焦点在输入框、菜单、对话框、终端里时不生效。
- `↵`：焦点回输入框，规则见上。
- 这两个键是"手离开键盘输入区之后"的键，配合 `⌃E` 用：`⌃E` → `j` / `k` 读 → `↵` 继续写。

## 九、原本就有的键（未改动，一并列出）

### 输入框

| 键 | 作用 |
|---|---|
| `↵` | 发送（默认；设置里可改成 `↵` 换行、`⌘↵` / `⌃↵` 发送） |
| `⇧↵` | 换行 |
| `↑` | 输入历史（输入框为空时）；菜单里是上移 |
| `↓` | 历史 / 菜单下移 |
| `/` | 斜杠命令菜单 |
| `@` | 文件、笔记提及菜单 |
| `!` | shell 模式（`!` 开头的消息当命令跑） |
| `Tab` | 接受当前菜单项（斜杠、`@`、历史） |
| `Esc` | 先关菜单；没有菜单且在跑 → 停止运行；没有菜单也没在跑 → 不做事（停止要按这里，退出编辑区用 `⌃E`） |
| `⌃↵` | 发送（`↵` 设成换行时用它发；焦点不在输入框里时它是“回输入框”） |
| `⌘V` / 粘贴图片 | 图片作为附件 |

### 对话区

| 键 | 作用 |
|---|---|
| `Esc` | 停止正在跑的会话（焦点不在输入框里时） |

### 文件查看器

| 键 | 作用 |
|---|---|
| `⌃I` | 源码模式下把选中的行作为提及插进输入框 |

### 右侧面板标签条

| 键 | 作用 |
|---|---|
| `←` `→` `Home` `End` | 焦点在标签上时切换标签 |

### 侧栏菜单（行右键菜单、项目菜单等）

| 键 | 作用 |
|---|---|
| 字母 | 菜单项的快捷键字母（右边有标注）直接触发该项 |
| `↑` `↓` `Home` `End` | 上下走 |
| `↵` | 打开 |
| `Esc` | 关闭 |
| 任意可打印字符 | 在菜单的过滤框里筛选 |
| `Tab` | 离开菜单（关闭） |

### 对话框

| 键 | 作用 |
|---|---|
| `Esc` | 关闭最上面那一层（Settings 上面叠了信任对话框时，只关上面那个） |
| `Tab` / `⇧Tab` | 对话框内循环焦点 |

### 其它

| 键 | 作用 |
|---|---|
| `⌃⌥N` | 新建会话（较早的全局快捷键，保留） |

## 十、代码结构与加一个新键

```
lib/shortcuts/
  keys.ts              认键：哪个 keydown 是哪个快捷键，以及什么时候这个键属于别人
  leader.ts            ⌃E 之后那张表（加一条命令就改这里）
  useShortcuts.ts      唯一的 window keydown 监听者，顺序 = 优先级
  ShortcutHint.tsx     ⌃E 之后的提示条
  scroll.ts            聊天区滚动入口（ChatWindow 注册，j / k 调它）
  keys.test.mjs        键位断言，含"不碰浏览器键"的回归
```

加一个全局键：

1. `keys.ts` 加一个 matcher（纯函数，参数是 `ShortcutEvent`）。
2. `useShortcuts.ts` 在合适的位置插入判断——顺序就是优先级：
   弹层守卫 → `⌃E` 那一轮 → `⌃E` 本身 → 带修饰的跳转（输入框里也生效）→
   `isEditableTarget` 守卫 → 裸键。
3. `ShortcutHandlers` 加一个回调，AppShell 里接上真正的动作。
4. `keys.test.mjs` 补一条断言（尤其要断言它不会误吃别的组合键）。

加一条 `⌃E` 命令：只改 `leader.ts` 的 `LEADER_COMMANDS` 和 `useShortcuts.ts` 的 `runLeader` 分派。

## 十一、限制与注意事项

- **只认看得见的会话。** 折叠分组、`show more` 之外的会话不在跳转顺序里；未读 / 运行中的目标藏在折叠组里时，第一下会先展开组。
- **`⌘↑` / `⌘↓` 覆盖了浏览器的"滚到页首页尾"**，`⌘⇧↑↓` 覆盖了"选到页首页尾"。这个页面本身不整页滚动，所以没有实际损失。
- **`⌃E` / `⌃N` 覆盖了 macOS 文本框里的 emacs 光标移动**（行尾、下一行）。这是刻意的：它们现在是全局快捷键。
- **`⌃⇧↑↓` 覆盖了文本框里"按词选中"**。
- **手机端不启用**（没有物理键盘）。
- 如果浏览器装了 Vimium 一类单键插件，裸 `j` / `k` 会跟它对上，二选一关掉。
- 停止运行仍然只有 `Esc`（输入框里或页面空白处）。跑着的时候想出去看别的、又不想停，用 `⌃E`。
